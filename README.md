# Little Words Picture Quiz

A static React reading quiz for early readers. Each round shows a picture and four different 3- or 4-letter word choices.

## Local

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Deploy

The GitHub Pages workflow builds with the `/little-words-picture-quiz/` base path:

```bash
npm run build:gh
```
